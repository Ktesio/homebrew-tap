# Ktesio Homebrew Tap

Homebrew tap for the Ktesio org's command-line tools.

## Install skm

After an `skm` release publishes its formula:

```bash
brew install ktesio/tap/skm
```

Or tap the repository first:

```bash
brew tap ktesio/tap
brew install skm
```

Formulae live under `Formula/` and are updated by each project's release workflow.
